# Synthetic data

The CSV in this folder is generated by scripts/make_data.py.
Run the script from the repository root with python scripts/make_data.py or make data.
It creates 2,880 hourly rows for three example sites, using a fixed random seed.
The temperature and power columns contain 50 inserted missing values in total.
scripts/generate_figures.py fills those gaps by time-ordered linear interpolation.
Power is generated from temperature, random noise, and fixed offsets by site.
The data are synthetic and are not measurements from real buildings or sensor networks.
The output file is data/sensor_experiment.csv.\nThe CSV is ignored by Git because it can be recreated from the script.
Do not edit the generated CSV by hand; change the generator if the example data need to change.
