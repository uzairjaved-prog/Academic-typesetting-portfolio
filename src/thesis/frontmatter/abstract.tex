\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}
This document demonstrates a modular thesis-production workflow in \LaTeX. It uses a reproducible, entirely synthetic dataset containing \Nobs{} hourly observations across three example monitoring sites to illustrate data preparation, a hinge-regression model, mathematical notation, tables, and publication-style figures. The source is organized into a reusable preamble, independent chapters, appendices, bibliography, and index. All data and graphics are generated by the accompanying Python scripts. This is a typesetting sample, not a claim of empirical research or an academic qualification.
