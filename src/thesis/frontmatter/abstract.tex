\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}
This thesis-layout sample uses 2,880 hourly observations from three example monitoring sites. The data are synthetic and generated by a fixed-seed Python script. The document shows how to organize a long LaTeX project, state a regression model, include diagrams and figures, and manage references and appendices. The fitted hinge model has an in-sample coefficient of determination of \hingeRtwo{} on the generated data. This value describes the fit to these rows; it is not a test of performance on new data. The control-system figures are separate illustrations and are not tests on the dataset.
