\chapter{Conclusion}\label{ch:concl}

The fitted hinge regression has an in-sample $R^2$ of \hingeRtwo{} on the generated observations. The data were created from a temperature-based formula with site offsets, so this statistic describes how the fitted curve represents the example data. It is not evidence about real monitoring sites, a causal effect, or accuracy on new observations.

The PID block diagram and the second-order step-response plot illustrate a feedback-control structure and the effect of changing damping. No controller was tuned against the generated dataset, and no physical system was controlled.
