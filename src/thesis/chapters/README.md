# Thesis chapters

These five files are included by [../main.tex](../main.tex) in this order:

1. [ch1_intro.tex](ch1_intro.tex) — purpose and questions.
2. [ch2_literature.tex](ch2_literature.tex) — software, estimation and control background.
3. [ch3_methodology.tex](ch3_methodology.tex) — synthetic data, hinge regression and diagrams.
4. [ch4_results.tex](ch4_results.tex) — generated summaries and model fit.
5. [ch5_conclusion.tex](ch5_conclusion.tex) — limits and conclusions from the example.

Build the complete thesis from the repository root with make thesis. Chapter text belongs in these files; shared formatting is in [../preamble.tex](../preamble.tex).
