# Thesis chapters

This folder contains the five main chapters, from introduction to conclusion.
main.tex includes them in reading order with the LaTeX include command.
The chapter labels are used for cross-references within the thesis.
Build the complete thesis from the repository root with make thesis.
For a fast draft, use the includeonly line in src/thesis/main.tex.
Each chapter should contain its own headings, prose, equations, and local figures.
Shared packages and page formatting belong in ../preamble.tex, not here.
Figures are generated by python scripts/generate_figures.py or make figures.
The built chapter content appears in src/thesis/main.pdf.\nEdit the .tex files; do not edit generated PDFs or auxiliary files.
