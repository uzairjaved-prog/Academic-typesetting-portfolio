# Changelog

All notable changes are documented here. Format: [Keep a Changelog](https://keepachangelog.com/), versioning: [SemVer](https://semver.org/).

## [1.0.0] - 2026-11-09
### Added
- IEEEtran journal paper with advanced mathematics, booktabs/siunitx tables and BibTeX.
- Native TikZ/PGFPlots diagrams (Transformer, FSM, PID loop, step response) with shared styles.
- Reproducible Python pipeline (pandas, matplotlib, seaborn) exporting vector figures and LaTeX tables.
- Multi-file thesis architecture (preamble, `\include` chapters, TOC/LOF/LOT, index, appendices).
- GitHub Actions CI: lint, build, undefined-reference gate, checksummed PDF artifacts, tagged releases.
