# Services and scope

This page describes the kinds of document work represented by the repository examples. It is a scope guide, not a price list or a promise that every project uses the exact same files.

| Work area | Examples shown here | Typical inputs needed for a real project |
|---|---|---|
| LaTeX paper formatting | IEEE-style layout, equations, citations, figures, and tables | Manuscript, target template, bibliography, and submission instructions |
| Thesis and dissertation layout | Title page, abstract, contents, chapters, appendices, bibliography, and index | Institutional template, text, required front matter, and citation style |
| Mathematical typesetting | Aligned equations, matrices, operators, and estimator notation | Source equations, notation conventions, and any required numbering |
| TikZ and PGFPlots | Architecture diagrams, state diagrams, block diagrams, and curves | Sketch, written specification, labels, and final page dimensions |
| Research figures and tables | Python plots, summary statistics, and LaTeX table integration | Data, variable definitions, units, and preferred figure/table formats |

## What is included in this repository

The journal paper and thesis are synthetic examples. Their data are generated by scripts/make_data.py. The plots and summary tables are created by scripts/generate_figures.py. The TikZ diagrams are written as LaTeX source under src/tikz/.

## Project boundaries

The examples do not represent a real university submission, field study, or tested control system. For client work, the supplied manuscript, data, institutional requirements, and citation instructions define the scope. Any requested analysis beyond formatting should be agreed separately.
